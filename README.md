## 🎨 Features
- External CSS stylesheets for **each page**. 
- Shared **navigation bar** (`nav.css`) for consistent design across all pages. 
- Responsive design using **flexbox, grid, relative units, and media queries**. 
- CSS hover effects for interactivity. 
- Clean typography and consistent color scheme. 

---

## 🚀 How to Run
1. Clone or download the repository. 
2. Open `index.html` in any web browser. 
3. Navigate between pages using the menu bar. 

---

## 🛠️ Technologies Used
- **HTML5** 
- **CSS3 (Flexbox, Grid, Media Queries)**
